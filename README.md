**Note!** The dependencies used in this repo are out of date. Get them from their respective repos in this organization instead, found here: [DRV](https://github.com/AHSPC/DRV8833_micropython), [VL53](https://github.com/AHSPC/VL53L4CD_micropython)

This repository contains all the necessary files (libraries) needed to use both the DRV8833 dual motor driver as well as the VL53L4CD ToF distance sensor in MicroPython, as well as some tests / challenges.
